## 1. Встановлення

**Потрібно:** Python 3.12 або новіший і близько 400 МБ на диску (здебільшого це набір Qt).

### Windows

1. Встановіть Python 3.12+ з [python.org](https://www.python.org/downloads/) (позначте *Add python.exe to PATH*).
2. Відкрийте PowerShell у теці, де хочете мати програму, і виконайте:

```powershell
git clone https://github.com/nkhp8djnyt-max/easy-db.git
cd easy-db
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[gui]"
python -m easydbms
```

### macOS

```bash
git clone https://github.com/nkhp8djnyt-max/easy-db.git
cd easy-db
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e ".[gui]"
python -m easydbms
```

### Linux

Спершу встановіть системні бібліотеки Qt (назви для Debian / Ubuntu; в інших дистрибутивах є відповідники):

```bash
sudo apt install python3.12-venv libegl1 libgl1 libxkbcommon0 libfontconfig1 libdbus-1-3 libxcb-cursor0
git clone https://github.com/nkhp8djnyt-max/easy-db.git
cd easy-db
python3.12 -m venv .venv
. .venv/bin/activate
pip install -e ".[gui]"
python -m easydbms
```

### Повторний запуск

Відкрийте термінал у теці `easy-db`, активуйте середовище (`. .venv/bin/activate` або `.venv\Scripts\Activate.ps1` у
Windows) і виконайте `python -m easydbms` (або просто `easydbms`). Щоб оновитися, виконайте `git pull` і ще раз
`pip install -e ".[gui]"`.

### Додаткові пакети

| Команда | Що додає |
|---|---|
| `pip install -e ".[cloud]"` | Бібліотеки входу в AWS, Azure і Google Cloud (див. [розділ 5](#5-хмарні-бази-даних)) |
| `pip install -e ".[aws]"`, `".[azure]"`, `".[gcp]"` | Лише одну з них |
| `pip install -e ".[gui,build]"` | Інструменти для збирання окремої теки із застосунком |

### Окрема тека із застосунком

Якщо ви не хочете запускати програму з терміналу, зберіть теку із готовим застосунком:

```bash
pip install -e ".[gui,cloud,build]"
python scripts/build_app.py --check
```

Результат — `dist/EasyDBMS/`; запускайте звідти `EasyDBMS` (`EasyDBMS.exe` у Windows), а в macOS відкрийте
`dist/EasyDBMS.app`. Теку можна скопіювати на інший комп'ютер із такою самою операційною системою.

## 2. Перший запуск

Вікно має три частини: **область запитів** ліворуч (угорі редактор, унизу результати), **діаграму** праворуч і рядок
меню: **Файл**, **Запит**, **База даних** і **Вигляд**. Доки ви не підключилися, ліворуч написано *Підключення не
вибрано* й є кнопка **Підключення…**.

- **Мова:** *Вигляд → Мова* (*Як у системі*, *Українська*, *English*). Вона застосується під час наступного запуску
  програми. За замовчуванням береться мова вашої системи: українська для українських систем, інакше англійська.
- **Тема:** *Вигляд → Системна тема / Темна тема / Світла тема*. Системна тема слідує за вашою операційною системою й
  перемикається сама, коли вона перемикається.
- **Ліміт рядків:** *Запит → Ліміт рядків* задає, скільки рядків зберігає результат (100, 1 000, 10 000 або 100 000).
  Більший результат обрізається, і таблиця про це повідомляє.

## 3. Підключення до бази даних

Відкрийте **Підключення…** (<kbd>Ctrl+Shift+C</kbd>). Ліворуч — ваші збережені підключення, згруповані; праворуч —
форма вибраного.

### SQLite

1. Натисніть **+ Нове** і виберіть **SQLite**.
2. Натисніть **Відкрити…**, щоб вибрати наявний файл, або **Створити…**, щоб створити новий (позначка *Створити файл,
   якщо його немає* тоді ставиться сама). Шлях `:memory:` дає тимчасову базу, що зникає після відключення.
3. Введіть **Назву** вгорі й натисніть **Підключитися**.

### PostgreSQL і MySQL / MariaDB

1. Натисніть **+ Нове** і виберіть **PostgreSQL** або **MySQL / MariaDB**.
2. Заповніть форму одним із двох способів:
   - вкладка **Хост / порт**: хост, порт (порожній означає типовий, 5432 або 3306), користувач, база даних і за
     потреби *Додаткові параметри*, наприклад `connect_timeout=5`;
   - вкладка **URL**: вставте URL підключення, наприклад `postgresql://app@db.example.com:5432/shop?sslmode=require`.
     Поля заповняться самі, а редагування поля переписує URL. Пароль з URL переноситься в поле пароля й ніколи не
     лишається в URL.
3. Введіть **Пароль**. Залиште позначеним **Зберегти пароль**, щоб тримати його в системному сховищі (keyring) або в
   зашифрованому сховищі (див. нижче); зніміть позначку, щоб програма питала пароль щоразу.
4. Дайте підключенню **Назву**, а за бажання **Колір** і **Групу**, щоб довгий список лишався впорядкованим.
5. Натисніть **Перевірити**, потім **Підключитися**.

**Робоча база та лише читання.** Позначте **Робоча (production) база** для всього справжнього: підключення отримає
червону мітку й смугу, а програма питатиме підтвердження перед зміною даних. Позначте **Лише читання**, і сесія
відмовлятиме будь-який запис.

**Підстановки.** Будь-яке текстове поле може містити `${NAME}` або `${NAME:-запасне}`; під час підключення воно
замінюється значенням змінної середовища, тож збережене підключення не містить секретів і шляхів, прив'язаних до
комп'ютера. Щоб отримати буквальне `${`, пишіть `$${`.

### Що показує *Перевірити*

*Перевірити* проходить підключення крок за кроком і зупиняється на першому, що не вдався, з порадою:

| Крок | Що перевіряється |
|---|---|
| Файл сервісів, Джерело пароля | Чи знайдено `pg_service.conf` і `~/.pgpass` та який рядок використано |
| Хмарний токен | Чи вдалося створити токен входу в хмару ([розділ 5](#5-хмарні-бази-даних)) |
| SSH: проміжний вузол, SSH: вхід, SSH-тунель | Бастіон, SSH-сервер і шлях до бази даних |
| Пошук адреси (DNS), Порт доступний | Ім'я розв'язується, і щось слухає на порту (за тунелем пропускається) |
| Файли TLS | Ваші файли сертифіката й ключа існують, чинні та підходять один до одного |
| Вхід, Шифрування | Вхід вдався; яку версію TLS і який шифр узгоджено |
| Тестовий запит | Виконався `SELECT 1` |

### Сховище паролів

Паролі потрапляють у системне сховище (Windows Credential Manager, macOS Keychain, Secret Service у Linux). Якщо
жодного немає, EasyDBMS використовує **зашифрований файл-сховище**, захищений майстер-паролем, який програма питає
вперше, коли він знадобиться. Нічого секретного не записується в `connections.json`.

## 4. Безпечні підключення

Відкрийте вкладки **SSL / TLS** і **SSH-тунель** підключення.

### SSL / TLS

| Режим | Значення |
|---|---|
| За замовчуванням (драйвер) | Як вирішить драйвер: PostgreSQL спершу пробує TLS, MySQL використовує його, коли сервер пропонує |
| `disable` | Без шифрування |
| `allow` (PostgreSQL) | Спершу без шифрування; TLS, лише якщо цього вимагає сервер |
| `prefer` | TLS, якщо сервер його пропонує, інакше без шифрування |
| `require` | Завжди зашифровано, але сервер не перевіряється |
| `verify-ca` | Зашифровано, і сертифікат має бути підписаний вашим CA (або системним) |
| `verify-full` | Як `verify-ca`, і сертифікат має збігатися з іменем хоста |

Вкажіть **Сертифікат CA** для `verify-ca` / `verify-full` із приватним центром сертифікації. Якщо сервер просить
клієнтський сертифікат, заповніть **Клієнтський сертифікат** і **Клієнтський ключ** (а також **Парольну фразу ключа**,
якщо ключ зашифровано; її зберігають так само, як пароль). *Перевірити* спершу перевіряє файли й називає проблему:
файл відсутній, це не сертифікат, термін дії минув (з датою), ключ не підходить, хибна парольна фраза.

### SSH-тунель

Позначте **Підключатися через SSH-тунель**, потім заповніть **SSH-сервер**: хост, порт, користувача та **Спосіб
входу**: *ssh-agent*, *Пароль* або *Закритий ключ* (з його файлом і, якщо вона є, парольною фразою). *Хост* на
головній вкладці тоді — це хост бази даних **так, як його бачить SSH-сервер**, наприклад `10.0.3.17` або `localhost`.

Щоб дістатися до SSH-сервера через бастіон, позначте **Підключатися до SSH-сервера через проміжний вузол (бастіон)**
й заповніть другий блок.

**Довіра до сервера.** Коли ви вперше підключаєтеся до SSH-сервера, його ключ ще невідомий. *Перевірити* (або сторінка
помилки підключення) показує його відбиток і кнопку **Довіряти цьому серверу…**. Звірте відбиток з тим, що дав вам
адміністратор, і лише тоді довіряйте. Якщо ключ, якому ви довіряли, **змінився**, підключення відхиляється: це означає
або що сервер перевстановили, або що хтось перехоплює з'єднання. Довірені ключі лежать у файлі `known_hosts` у вашій
теці конфігурації, а файл `~/.ssh/known_hosts` також враховується.

Тунель відкривається автоматично перед підключенням і закривається, коли ви відключаєтеся.

### `~/.pgpass` і `pg_service.conf` (PostgreSQL)

- Якщо в підключення немає збереженого чи введеного пароля, шукається `~/.pgpass` (змінна `PGPASSFILE` змінює
  розташування). У Linux і macOS файл не повинен читатися іншими (`chmod 0600 ~/.pgpass`), інакше його ігнорують, і
  форма про це повідомляє.
- Введіть назву **Сервісу** (або виберіть зі списку знайдених) на вкладці *Хост / порт*. Усе, що підключення лишає
  порожнім (хост, порт, користувач, база даних, файли TLS), береться з `pg_service.conf`; те, що ви заповнили, завжди
  має пріоритет. Хост може лишатися порожнім, якщо його дає сервіс.

## 5. Хмарні бази даних

Відкрийте вкладку **Хмара** і виберіть свій сервіс; форма заповнить, що зможе, не перезаписуючи введене вами.

| Сервіс | Як відбувається вхід | Що потрібно |
|---|---|---|
| AWS RDS / Aurora (IAM) | Токен на 15 хвилин, створюваний з ваших облікових даних AWS щоразу | `pip install -e ".[aws]"`; облікові дані зі змінних середовища, `~/.aws` або ролі. Регіон і профіль за бажанням |
| Google Cloud SQL (IAM) | Токен доступу вашого облікового запису Google | `pip install -e ".[gcp]"`; `gcloud auth application-default login` або файл ключа сервісного акаунта. Підключайтеся до IP екземпляра або до запущеного Cloud SQL Auth Proxy |
| Azure Database (Entra ID) | Токен доступу Entra | `pip install -e ".[azure]"`; `az login` або змінні `AZURE_*`. Користувач — ім'я субʼєкта Entra |
| Supabase | Звичайний пароль | Ідентифікатор проєкту підставляє `db.<ref>.supabase.co` |
| Neon | Звичайний пароль | Вставте хост із консолі Neon |
| PlanetScale | Звичайний пароль | MySQL; сертифікат перевіряється |
| CockroachDB Cloud | Звичайний пароль | Порт 26257; для Serverless назва кластера йде перед назвою бази; виберіть CA-сертифікат кластера на вкладці TLS |

Для перших трьох **поля пароля немає**: токен створюється щоразу, коли відкривається підключення, показується як крок
*Хмарний токен* у *Перевірити* і за потреби поновлюється. Якщо бібліотеку входу не встановлено, *Перевірити* підкаже,
який саме додатковий пакет потрібен. Користувач бази має бути ввімкнений для входу через IAM / Entra на боці сервера.

## 6. Написання й виконання SQL

- **Вкладки:** <kbd>Ctrl+T</kbd> нова, <kbd>Ctrl+W</kbd> закрити, подвійне клацання по назві вкладки перейменовує її.
  Вкладки й їхній текст повертаються, коли ви наступного разу відкриваєте підключення. Список поруч із *Виконати*
  задає діалект вкладки.
- **Виконання:** <kbd>Ctrl+Enter</kbd> виконує виділене або оператор під курсором; <kbd>F5</kbd> (*Виконати скрипт*)
  виконує всі оператори по черзі. Кожен оператор отримує власну вкладку результату. Оператор, що завершився помилкою,
  зупиняє скрипт і позначає місце помилки в редакторі; решта показуються як пропущені.
- **Зупинка:** <kbd>Esc</kbd> або кнопка **Зупинити** скасовує оператор, що виконується, на сервері.
- **Форматування:** <kbd>Ctrl+Shift+F</kbd> форматує виділене або весь текст за діалектом вкладки.
- **Автодоповнення:** підказки з'являються під час введення й після `.`; <kbd>Ctrl+Space</kbd> відкриває їх на
  вимогу. Користуйтеся <kbd>↑</kbd> / <kbd>↓</kbd> і <kbd>Enter</kbd> або <kbd>Tab</kbd>. Пропонуються ключові слова,
  таблиці (після `FROM` і `JOIN` спершу йдуть таблиці), стовпці псевдонімів, які ви написали, CTE та сніпети; після
  `JOIN` умова `ON` пропонується із зовнішнього ключа. Варіанти, які ви вибираєте часто, піднімаються вгору. *Запит →
  Регістр ключових слів* задає, чи вставлені ключові слова пишуться верхнім регістром, нижнім чи як введено. Щоб
  закрити список, натисніть <kbd>Esc</kbd>.
- **Безпека:** оператор, що видаляє чи очищає щось, або видаляє / змінює всі рядки таблиці, спершу питає підтвердження.
  На робочому підключенні питає й кожен оператор, що змінює дані.

## 7. Діаграма

Діаграма показує таблиці підключеної бази зі стовпцями (символи ключів позначають первинні й зовнішні ключі) та
зв'язки між ними: «пташина лапка» — це сторона «багато».

- **Пересування:** коліщатко миші змінює масштаб, перетягування фону — пересуває, кнопки **+ / − / ⛶** або
  <kbd>Ctrl++</kbd>, <kbd>Ctrl+-</kbd>, <kbd>Ctrl+0</kbd> (вмістити все). Перетягніть картку, щоб переставити;
  положення запам'ятовуються.
- **Вибір:** клацніть таблицю, щоб підсвітити пов'язані з нею таблиці. Клацніть стовпець, щоб вставити його назву в
  редактор.
- **Відкрити дані:** двічі клацніть картку. Правою кнопкою — *Відкрити дані*, *SELECT \* FROM ця таблиця*, *Вставити
  назву таблиці*, *Копіювати назву таблиці*.
- **Пошук:** введіть текст у поле над діаграмою, щоб залишити лише таблиці й стовпці, що збігаються.
- **Схеми:** за кількох схем список дозволяє вибрати одну або *Усі схеми*.
- **Оновлення:** ↻ (або <kbd>Ctrl+Shift+R</kbd>) перечитує структуру після змін; ⟲ скидає розташування карток.
- **Перехід до таблиці:** <kbd>Ctrl+P</kbd> знаходить таблицю чи стовпець за кількома літерами.
- **Сховати:** *База даних → Показати діаграму* згортає праву частину.

### Експорт

*База даних → Експорт діаграми…* (<kbd>Ctrl+E</kbd> або кнопка ⤓) зберігає діаграму як **PNG**, **SVG**, **PDF** або як
текст: **Mermaid** `erDiagram` чи **DBML** (його можна вставити в інші інструменти). Зображення містять лише картки,
що показані зараз (після пошуку); текстові формати перелічують усі таблиці вибраної схеми.

## 8. Перегляд і редагування даних

Двічі клацніть картку таблиці, щоб відкрити її дані у вкладці. Клацніть заголовок стовпця, щоб відсортувати (на
сервері, тож це працює на мільйонах рядків), введіть умову `WHERE` у полі фільтра, гортайте ◀ ▶, оновлюйте ⟳.

Можна також редагувати результат простого `SELECT * FROM table WHERE …`, введеного в редакторі. З'єднання,
групування, `DISTINCT`, представлення й підключення лише для читання редагувати не можна, а рядок під таблицею
пояснює чому.

### Внесення змін

| Що робити | Клавіші |
|---|---|
| Змінити комірку | <kbd>F2</kbd> або подвійне клацання; відкривається редактор, що підходить типу (календар, список true / false / NULL, поле числа) |
| Записати NULL, використати типове значення, редагувати довгий текст у вікні | Права кнопка на комірці |
| Додати рядок | <kbd>Ctrl+N</kbd> |
| Дублювати виділені рядки | <kbd>Ctrl+D</kbd> |
| Позначити рядки на видалення (повторно — відновлює) | <kbd>Del</kbd> |
| Скасувати / повторити | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> |
| Відхилити все, що очікує | <kbd>Esc</kbd> |
| Переглянути й записати | <kbd>Alt+S</kbd> |

Змінені комірки жовтіють (наведіть курсор, щоб побачити старе значення), нові рядки стають зеленими, рядки на видалення
— червоними й закресленими. Ваші правки переживають сортування, фільтрацію, гортання й оновлення.

### Перегляд, потім одна транзакція

<kbd>Alt+S</kbd> відкриває перегляд із SQL, який буде виконано (зі значеннями, виписаними повністю), і кількістю
рядків, що змінюються, додаються чи видаляються. Натисніть **Застосувати**, щоб записати все **однією транзакцією**:
або все, або нічого. На робочому підключенні потім іде ще одне підтвердження.

### Якщо рядок змінив хтось інший

Оновлення шукає рядок за його ключем **і** за старими значеннями комірок, які ви змінили. Якщо рядок тим часом
змінили чи видалили, уся транзакція відкочується (*Нічого не записано*), рядок називається, а ваші правки лишаються в
таблиці. Натисніть **Оновити**, щоб накласти їх на поточні дані, і застосуйте знову.

### Таблиці без первинного ключа

Таблицю без первинного ключа все одно можна редагувати, якщо в неї є унікальний індекс. Інакше виберіть **Вибрати
ключові стовпці…** і позначте стовпці, що ідентифікують рядок; вибір запам'ятовується. Зміна, що торкнулася б більше
ніж одного рядка, відхиляється.

Закриття вкладки, виконання іншого запиту поверх відредагованого результату чи вихід із програми, поки є незастосовані
зміни, спершу питає підтвердження.

## 9. Історія та збережені запити

- **Історія** (<kbd>Ctrl+H</kbd>): кожен оператор, що ви його виконали на підключенні, з часом, тривалістю, кількістю
  рядків і помилкою, якщо була. Шукайте, показуйте лише помилки, відкривайте запис у новій вкладці, вставляйте в
  позицію курсора, копіюйте, зберігайте як запит чи видаляйте. Повторне виконання того самого оператора одразу після
  себе лише збільшує лічильник запусків (`x3`). *Очистити історію…* спершу питає.
- **Зберегти запит** (<kbd>Ctrl+S</kbd>): зберігає виділене (або весь редактор) під назвою, у необов'язковій папці,
  наприклад `Reports/Monthly`. Позначте *Лише для цього підключення*, щоб не показувати його в інших підключеннях.
- **Збережені запити** (<kbd>Ctrl+Shift+H</kbd>): перегляд, пошук (за назвами й текстом), відкриття в новій вкладці,
  вставлення, перейменування, переміщення до папки, видалення.

## 10. Налаштування та файли

Меню *Запит* і *Вигляд* змінюють ліміт рядків, регістр ключових слів, тему й мову; їх зберігає `settings.toml`. Усе
інше — у вікні підключення.

| Файл | Де | Що |
|---|---|---|
| `connections.json` | тека конфігурації | Ваші підключення (без паролів) |
| `settings.toml` | тека конфігурації | Тема, мова, ліміт рядків, регістр ключових слів |
| `vault.json` | тека конфігурації | Зашифровані паролі, лише якщо не використовується системне сховище |
| `known_hosts` | тека конфігурації | SSH-сервери, яким ви довірили |
| `app.db` | тека даних | Вкладки запитів, історія, збережені запити, положення діаграми, використання автодоповнення |

У Linux це `~/.config/easydbms` і `~/.local/share/easydbms`; у macOS обидві — `~/Library/Application
Support/easydbms`; у Windows — `%LOCALAPPDATA%\easydbms`. Задайте змінну середовища `EASYDBMS_HOME` на теку, щоб
тримати все там (так програма стає переносною). Пошкоджені `connections.json` чи `settings.toml` ніколи не
перезаписуються: файл перейменовується на `*.broken-<час>`, а програма стартує з того, що вдалося прочитати, і каже вам
про це.

**Почати з нуля:** закрийте програму й видаліть обидві теки. Це також видалить ваші збережені підключення та історію;
паролі із системного сховища можна прибрати власним менеджером сховища (шукайте записи з назвою `easydbms`).

## 11. Вирішення проблем

**Вікно не відкривається в Linux** (`Could not load the Qt platform plugin "xcb"`). Встановіть бібліотеки з
[розділу 1](#linux), зокрема `libxcb-cursor0`.

**`pip install` каже, що версія Python застара.** EasyDBMS потребує Python 3.12 або новішого. Перевірте
`python --version` і створіть середовище командою `python3.12 -m venv .venv`.

**Перевірка каже, що крок «Порт доступний» не вдався.** Хост знайдено, але на цьому порту ніхто не приймає
підключень. Перевірте, чи запущено сервер, номер порту, а також брандмауер чи VPN. За SSH-тунелем хост і порт — це ті,
до яких може дістатися **SSH-сервер**.

**Пароль відхиляється, хоча він правильний.** Перевірте користувача й назву бази та те, який пароль використовується:
збережений має перевагу над `~/.pgpass`. Якщо ви зберегли хибний пароль, введіть правильний у поле й збережіть знову.

**Помилки TLS.** *Перевірити* називає файл чи крок. «certificate verify failed» із `verify-full` зазвичай означає, що
ім'я хоста в підключенні відрізняється від імені в сертифікаті; використайте ім'я, на яке видано сертифікат, або
`verify-ca`. З приватним CA вкажіть його сертифікат у полі **Сертифікат CA**.

**«Особа SSH-сервера ще невідома».** Скористайтеся **Довіряти цьому серверу…** після звірки відбитка. Якщо сказано, що
ключ **змінився**, не підключайтеся, доки не зʼясуєте причину.

**`~/.pgpass` ігнорується.** Виконайте `chmod 0600 ~/.pgpass`. Форма підключення показує, чи знає файл це підключення
(сам пароль — ніколи).

**«Невизначена змінна середовища».** Підстановка `${NAME}` не має значення й не має `:-запасного`. Задайте змінну до
запуску програми (програма, запущена з меню, може не бачити змінних, заданих у терміналі).

**Системним сховищем не можна скористатися.** На сервері чи в мінімальному сеансі стільниці служби сховища може не бути;
тоді програма питає майстер-пароль і веде зашифроване сховище.

**Хмарне підключення каже, що потрібен пакет.** Встановіть додатковий пакет, який воно називає, наприклад
`pip install -e ".[aws]"`, у тому самому середовищі, з якого запускаєте програму.

**Діаграма порожня** після змін у базі. Натисніть ↻ (<kbd>Ctrl+Shift+R</kbd>), щоб перечитати структуру.
